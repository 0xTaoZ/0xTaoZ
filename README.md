- [authlog-watch](https://github.com/0xTaoZ/authlog-watch): SSH authentication log summaries and a few triage rules.
- [sigma-rule-helper](https://github.com/0xTaoZ/sigma-rule-helper): checks for Sigma rule structure and conditions.
- [Sentinel-IOC-Toolkit](https://github.com/0xTaoZ/Sentinel-IOC-Toolkit): IOC extraction with optional AbuseIPDB enrichment.
- [java-web-log-triage](https://github.com/0xTaoZ/java-web-log-triage): a small Java CLI for web access logs.
- [StudyPulse](https://github.com/0xTaoZ/studypulse-app): a study planner with spaced reviews and recall checks, built on Cloudflare Workers and D1.
